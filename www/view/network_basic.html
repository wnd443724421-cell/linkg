命令由当前运行配置生成；保存后未重启的网段不会提前用于教程。静态配置只添加虚拟网络路由，不添加 Internet 默认路由。请使用连接 LinkG 的网卡，执行前记录原配置。

DHCP 已通过 Option 121/249 自动下发虚拟网段路由时，一般无需重复添加手工路由；静态 IP 用户需手工添加。租约有效期为 600 秒（10 分钟），服务重载不会立即更新客户端配置。

当前 DHCP 地址池覆盖 .2–.254，没有预留静态地址。DHCP 和手工静态 IP 混用可能冲突；请先确认地址空闲。静态 IP 不会因拔插网线自动改变。

Linux 永久示例使用 NetworkManager。先用 nmcli connection show 查出已有连接名称，再填写上方字段。专用于 LinkG 的连接不能同时作为原 Internet 出口；其他网卡的默认路由不受影响。非 NetworkManager 系统请使用 netplan、systemd-networkd 等对应机制，临时 ip 命令不会永久保存。

更新 DHCP 租约可使用下方系统命令，也可重新插拔网线；关闭 DHCP 后需要静态 IP。NetworkManager 断开再连接会短暂中断该网卡。Windows 添加静态地址可能关闭该网卡 DHCP，请先记录原 DHCP/网关配置；现有 Internet 默认网关不应改为 LinkG。
