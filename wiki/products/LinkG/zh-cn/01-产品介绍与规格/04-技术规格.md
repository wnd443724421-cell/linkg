# 技术规格

| 类别 | 项目 | 规格参数 |
|---|---|---|
| 硬件接口 | 对外接口 | 以太网、串口 |
| 硬件接口 | 网口速率 | 100 Mbps |
| 电气参数 | 电源输入 | 9～15 V |
| 机械参数 | 重量（不含天线） | 89 g |
| 机械参数 | 尺寸（长 × 宽 × 高） | 78 × 45 × 17 mm |
| 工作环境 | 工作温度 | -10～+50 ℃ |
| 工作环境 | 工作湿度 | 5%～85% RH（无凝露） |
| 通信与组网 | 传输链路 | Wi-Fi、4G LTE、5G NR SA |
| 通信与组网 | 组网方式 | AP/STA 星型组网；宽带：一对一、一对多；窄带：默认一对一，自适应模式仅支持一对一 |
| 通信与组网 | 宽带节点容量（软件上限） | 1 个 AP + 16 个 STA，共 17 个节点；不适用于窄带 |
| Wi-Fi | 工作模式 | 宽带、窄带 |
| Wi-Fi | 信道带宽 | 宽带：20/40/80 MHz；窄带：10 MHz |
| Wi-Fi | 窄带速率控制 | 固定档位 0～5、驱动自适应（仅支持一对一）；固定档位一对多需自行测试，不承诺节点数 |
| 蜂窝通信 | 网络模式 | 自动选择 4G/5G、仅 4G LTE、仅 5G NR SA |
| 网络服务 | 公网访问 | 通过 4G/5G 蜂窝网络为以太网接入设备提供互联网出口 |
| 业务传输 | 业务分类 | 实时、视频、普通数据；按 TCP/UDP 端口配置分类规则 |
| 串口传输 | 转发方式 | 串口与 TCP/UDP 网络之间单向或双向转发 |
| 串口传输 | SBUS | UART0 支持，固定 100000 baud、8E2 |
| 管理与维护 | 配置与状态 | Web 配置、链路状态查看、串口诊断、链路性能测试 |
| 管理与维护 | 系统维护 | 固件升级、重启、恢复出厂设置 |

产品介绍与通信方式见[产品概述](01-产品概述.md)。
