# 技术规格

| 项目 | 规格参数 |
|---|---|
| 网口数量 | 2 个（ETH0、ETH1） |
| 网口速率 | 100 Mbps |
| 串口数量 | 3 个（UART0、UART1、UART2） |
| 电源输入 | 9～15 V |
| 重量（不含天线） | 89 g |
| 尺寸（长 × 宽 × 高） | 78 × 45 × 17 mm |
| 工作温度 | -10～+50 ℃ |
| 工作湿度 | 5%～85% RH（无凝露） |
| 组网架构 | AP/STA 星型组网 |
| 宽带组网 | 一对一、一对多 |
| 宽带节点容量（软件上限） | 1 个 AP + 16 个 STA，共 17 个节点 |
| 窄带组网 | 默认一对一；自适应模式仅支持一对一 |
| Wi-Fi 工作模式 | 宽带、窄带 |
| 宽带信道带宽 | 20/40/80 MHz |
| 窄带信道带宽 | 10 MHz |
| 窄带速率控制 | 固定档位 0～5、驱动自适应 |
| 蜂窝网络制式 | 4G LTE、5G NR SA |
| 蜂窝网络模式 | 自动选择 4G/5G、仅 4G LTE、仅 5G NR SA |
| SBUS 支持接口 | UART0 |
| SBUS 串口格式 | 100000 baud、8E2（8 位数据位、偶校验、2 位停止位） |

窄带固定档位的一对多不属于默认支持范围，需用户在实际业务和环境中自行测试，不承诺接入数量。宽带节点容量上限不适用于窄带。

产品介绍见[产品概述](01-产品概述.md)，功能说明见[主要功能](02-主要功能.md)，接口与接线说明见[硬件与接口](03-硬件与接口.md)。
